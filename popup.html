Tab-split quick guide
  1. Add ---new tab--- lines to split prompts into tab sets (max 10 tab sets).
  2. If no ---new tab--- markers are present, automation runs sequentially.
  3. Optional: set a custom URL below. If empty, active tab URL is reused.
  4. Start automation. Each tab set gets one background tab; next launch starts as soon as the previous tab accepts its first prompt.
  5. Pause/Resume affects only new launches; already launched tabs keep running.
  6. Stop cancels pending launches only; launched tabs are left open.
